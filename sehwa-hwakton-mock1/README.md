# 세화여고 1학년 확률과 통계 — 모의고사 1회 오답노트 DB

- `DB/오답노트DB.hwp` : 1쪽 목차 + 문항(22개)당 1쪽. 한 쪽에 본문항 1개 + 동형·유사 3문항(2단 2x2), 정답은 미주.
- `분석_세화여고_기출_교과서_부교재_대조.md` : 중간고사·전년도 기출 분석, 교과서/부교재 대조, 모의고사 1회 설계·유형 분류.
- `DB/오답노트DB.json` : 문항별 출처·정답 표.
- `DB/세화여고1_확률과통계_기말_모의고사.hwp` : 모의고사 1회 원본.
- `모의고사1회_동형문항_매칭표.md`, `자체제작_동형문항_15_16_서술1.md` : 매칭표 / 자체 제작 동형(정답은 전수 계산으로 검증).
- `tools/` : HWP 생성 스크립트 (`python3 db_build.py 출력.hwp`, 양식은 `form.hwp`). 정답 검증은 `solve.py`, `variants.py`.
