## 2회차 만들기 (Windows + 한글)

```
cd "02. 수업자료\_제작도구"
python lesson_tpl.py content_02.py "..\2회차 (나머지정리) 11월 21일\2회차 수업자료 (나머지정리).hwp" pdf
```

## 원고 점검

```
python _분석도구\probs.py <2025 기출 HWP 폴더> gichul.json
python _분석도구\check_content.py content_02.py <오답DB\_제작도구\srcdb.json> gichul.json
```

기출 HWP 폴더는 `2025년 학교 1학년 1학기 중간고사 공통수학1.hwp`를 `학교.hwp`로 복사해 모은 폴더다.
원본 기출·교재 파일과 생성 결과물은 저장소에 넣지 않는다.
