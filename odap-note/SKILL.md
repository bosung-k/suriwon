# 오답노트 제작 프로토콜

스크립트 위치: 이 파일과 같은 폴더의 `scripts/` (아래 `$S`).
모든 명령은 `python "$S\<스크립트>" ...` 형태로 실행한다. 임시 파일(렌더·크롭 이미지, job.json)은 세션 scratchpad에 둔다.

## 0. 경로 확인 (매 작업 시작 시)

```
python "$S\setup_paths.py"
```
- Google Drive 경로는 PC마다 다르다. 자동 탐색이 실패하거나 `MISSING`이 있으면 **사용자에게 `01.수리원수학학원` 폴더 위치를 물어보고**
  `python "$S\setup_paths.py" --root "<경로>"` 로 지정한다. 설정은 `%USERPROFILE%\.claude\오답노트_config.json`에 저장된다.
- 기준 경로(학원 루트 기준):
  - 양식: `05. 강사별 폴더\00. 오답노트\오답노트 양식.hwp` (1쪽 = 문제 2개)
  - 저장: `05. 강사별 폴더\00. 오답노트\<선생님>T\<학생 폴더>\`
  - 교재: 초등 `100. 초등부`, 중등 `200. 중등부`, 고등 `300. 고등부`

## 1. 작업 지시서 읽기

1. `python "$S\pdf_tool.py" order "<지시서.pdf>" "<scratch>\order"` → PNG를 Read로 본다.
   가로로 누운 스캔이면 `--rotate 90`(또는 270)을 붙여 다시 렌더한다. 사진(jpg/png)이면 바로 Read.
2. 제목에서 **선생님**(예: "오답노트 리스트 – 현승T"), 각 행에서 **학생(학교·학년), 교재명, 쪽-번호**를 읽는다.
   - 손글씨 표기 예: `p157-29, 33, 35` = 157쪽 29·33·35번 / `1213, 1219` = 문제번호만(쪽 없음) / `2-1` = 학년-학기.
   - 빈 행(교재 없음)은 건너뛴다.
3. 읽은 내용을 **표로 정리해 사용자에게 확인받는다** (손글씨라 오독 가능성이 크다). 애매한 글자는 "?"로 표시하고 질문한다.

## 2. 학생 폴더 정하기

- `<오답노트>\<선생님>T\` 안에서 학생 이름이 들어간 기존 폴더를 찾아 그대로 쓴다.
- 없으면 그 선생님 폴더의 기존 이름 규칙을 따른다 (예: 현승T `이름(학교학년)` → `이시우(세화여중1)`, 보성T `(중3)이름`).
  선생님 폴더 자체가 없거나 규칙이 애매하면 사용자에게 확인 후 만든다.

## 3. 교재 찾기 (22개정 / 15개정은 반드시 사용자에게 묻는다)

```
python "$S\pdf_tool.py" books <초등|중등|고등> <키워드> [키워드...]
```
- 학교로 학교급을 정한다 (○○초 → 초등, ○○중 → 중등, ○○고 → 고등). 키워드는 교재명 일부 + 학년학기(예: `유형만렙 1-2`).
- 결과의 `[22개정]` / `[15개정]`(=새교육과정, 2019판) / `[?]` 태그를 보고, **어느 교육과정 교재인지 사용자에게 묻는다** (후보 경로를 함께 보여줌).
  같은 학기에 여러 판이 있으면 모두 보여준다.
- `[정답/해설]`, `교사용 부록`, `빠른정답` 파일은 문제 크롭용이 아니다. "문제", 학생용 본책을 우선 쓴다.
- 못 찾으면 키워드를 줄이거나(띄어쓰기·영문 약칭: RPM, 쎈, 만렙 등) 다른 학교급 폴더도 찾아보고, 그래도 없으면 사용자에게 파일 위치를 묻는다.

## 4. 쪽 → 번호 찾기

```
python "$S\pdf_tool.py" findpage "<교재.pdf>" <인쇄쪽수>      # PDF쪽(0부터) 추정
python "$S\pdf_tool.py" numbers  "<교재.pdf>" <PDF쪽> [번호]   # 문제번호 좌표
python "$S\pdf_tool.py" render   "<교재.pdf>" <PDF쪽> "<scratch>\pg.png"   # 눈금 렌더 → Read로 확인
```
- render 이미지의 오른쪽/아래 **인쇄 쪽수가 요청 쪽수와 같은지 눈으로 확인**한다.
- 번호가 그 쪽에 없으면 **앞뒤 ±2쪽**에서 찾는다. 교재가 4자리 번호(0956)나 유형번호(08-3)를 쓰는 등 지시서 표기와 다르면 가장 그럴듯한 대응을 찾는다.
- **쪽수·번호가 지시서와 다르게 매칭된 문제는 모두 기록**해 두었다가 최종 보고에서 알린다 (예: "요청 p157-29 → 실제 p158 29번").
  확신이 없으면 만들기 전에 사용자에게 묻는다.
- 스캔본(텍스트 없음)이면 numbers가 비어 있다 → render 이미지를 보고 좌표를 정한다.
- 쪽 없이 번호만 적힌 경우: `findnum <교재.pdf> 번호...` (텍스트 PDF). 번호가 그림 서체라 일부가 안 잡히면 근처 쪽을 render.
- 스캔본에서 쪽/번호 찾기: `thumbs <교재.pdf> <시작> <끝> <out.png> 50` 으로 여러 쪽을 한 장에 보고 범위를 좁힌 뒤 render.
- 흐린 손글씨 번호는 **번호가 보통 오름차순**이라는 점과 **같은 단원 범위 안**이라는 점으로 판단한다 (예: "576, 578"이 단원 밖이면 546, 548). 해석한 내용은 notice에 적는다.
- 학생의 기존 오답노트 파일명(교재·단원)을 보면 어떤 교재·판을 쓰는지 힌트가 된다.

## 5. 단원 (중단원 기준)

- `python "$S\pdf_tool.py" toc "<교재.pdf>"` 로 목차를 보고, 없거나 쪽번호뿐이면(많은 교재가 그렇다) 해당 쪽 머리말/옆 탭/목차 쪽을 render 해서 읽는다.
- **중단원** 이름을 교재 표기 번호와 함께 쓴다. 예: `1-2. 항등식과 나머지정리`, `08. 자료의 정리와 해석`, `2-1. 기본 도형`.

## 6. 문제 크롭

```
python "$S\pdf_tool.py" crop "<교재.pdf>" <PDF쪽> x0 y0 x1 y1 "<scratch>\crop_<쪽>_<번호>.png"
```
- 좌표는 render 이미지의 빨간 눈금(PDF pt) 기준. numbers 결과의 번호 위치에서 시작해 **다음 문제 번호 직전**까지, 단(column) 너비만큼 잡는다.
- 포함: 문제 본문, 보기(①~⑤), 그림·표, 그리고 **여러 문제가 공유하는 지문/자료** (예: `[0956~0959] 아래 자료는…` 과 표).
- 제외: 다른 문제, 소제목 띠(08-1 대푯값 등), '대표문제'·'쌍둥이 문제' 라벨, 쪽 머리말·쪽번호, 옆 단원 탭, 정답, **단 구분 세로선**.
- 홀수 쪽과 짝수 쪽은 단 위치가 10pt쯤 다르다 → 쪽마다 render 눈금으로 따로 잡는다 (안 그러면 번호 첫 글자가 잘림).
- **크롭 PNG를 반드시 Read로 열어 확인**하고, 잘렸거나 남는 게 있으면 좌표를 고쳐 다시 자른다.
- 문제가 다음 단/쪽으로 이어지면 두 조각을 각각 잘라 세로로 이어 붙인다.
- **여러 문제는 일괄 크롭이 편하다** (학생 1명 = spec 1개):
  ```
  python "$S\crop_batch.py" "<교재.pdf>" "<scratch>\ss.txt" "<scratch>" ss
  ```
  `ss.txt` 한 줄 = `번호 PDF쪽 x0 y0 x1 y1` (같은 번호 여러 줄 = 이어 붙이기). 결과 `ss_montage.png`를 Read로 확인하고,
  고칠 줄만 좌표를 바꿔 다시 실행한다.

## 7. HWP 만들기

job.json은 make_job.py로 만든다 (crop_batch 결과 이미지 이름 규칙과 맞춰짐):
```
python "$S\make_job.py" "<scratch>\job.json" 현승T "신재희(잠원초6)" "신재희 쎈 중2-1 11. 일차함수와 일차방정식의 관계 261021.hwp" "쎈 중2-1" "11. 일차함수와 일차방정식의 관계" "<scratch>\ss" 193:1213 194:1219
python "$S\build_note.py" "<scratch>\job.json"
```
job.json 형식 (직접 써도 됨, UTF-8):
```json
{
  "teacher": "현승T",
  "student_folder": "이시우(세화여중1)",
  "file_name": "이시우 유형만렙 중1-2 2-1. 기본 도형 261021.hwp",
  "items": [
    {"book": "유형만렙 중1-2", "unit": "2-1. 기본 도형", "page": "157", "num": "29", "image": "C:\\...\\crop_157_29.png"}
  ]
}
```
- 파일 이름: `<학생이름> <교재> <단원> <YYMMDD>.hwp` (날짜 = 작업일). 단원이 여럿이면 `2-1. ○○~2-2. △△`.
- 한 학생의 한 교재 = 파일 1개. 교재가 다르면 파일을 나눈다. 문제는 지시서 순서(쪽·번호 오름차순)대로.
- `교재` 칸은 짧게 교재명+학년학기 (예: `개념원리 공통수학1`, `RPM 중3-1`, `디딤돌 기본+응용 5-1`).
- 같은 이름 파일이 있으면 자동으로 `(2)`를 붙여 저장한다 (기존 파일은 덮어쓰지 않음).
  이번 작업에서 방금 만든 파일을 고쳐 다시 만들 때만, 그 파일을 지우고 다시 생성한다.
- 사용자가 중간에 "○○까지만"이라고 하면 그 학생까지만 저장하고, 크롭만 해 둔 학생은 저장하지 않는다.
- 실행 결과의 `PREVIEW_PDF`를 PNG로 렌더해서 **완성본을 눈으로 확인**한다 (글자 칸, 그림 크기, 쪽 수).

## 문제 해결
- 한글 실행/보안 팝업 문제: `install.bat` 재실행(보안모듈 등록).
- 숨은 한글(`Hwp.exe`, 창 제목 없음)이 남으면: `Get-Process Hwp | ? {-not $_.MainWindowTitle} | Stop-Process -Force`.
  창이 있는 한글은 사용자가 쓰는 문서일 수 있으니 끄지 않는다. '액세스 거부'로 안 꺼지는 것은 재부팅 시 사라진다.
- `win32com` 오류: `python -m pip install pywin32 pymupdf pillow`.
- 경로 문제: 0단계로 돌아가 사용자와 경로를 다시 잡는다.
